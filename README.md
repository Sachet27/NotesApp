# 📝 Noted App
Noted App is an easy-to-use and practical notes app. It is packed with tons of features so you can write you notes with ease!

## Features ✨
- **CRUD Operations**: Create, view, edit, and delete notes seamlessly.
- **Photo Attachments**: Insert and save photos locally for your notes. 
- **Theme Switching**: Manually toggle between in-app themes to suit your preference.
- **Modern UI**: Clean and user-friendly interface using Jetpack Compose.

## Tech Stack 🛠️
- **Kotlin**: Base language used in this app.
- **Jetpack Compose**: UI framework for Android.
- **Room Database**: Local database for efficient data storage and management.
- **Coil**: Image loading library for Kotlin to handle photo attachments.
  
### Requirements
Android device or emulator with API level 24 (Android Version 7.0) or above.
